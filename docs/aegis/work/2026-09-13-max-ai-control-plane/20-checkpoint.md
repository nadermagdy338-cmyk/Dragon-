## الجولة الختامية — إكمال سلسلة التفضيل (قرار #10)

كانت الفجوة الأخيرة: `setObjectivePreference` موجود في المحرك لكن الواجهة
لا تستدعيه — فالمستخدم لا يستطيع تحديد أولوياته فعليًا.

أُكملت السلسلة كاملة:
```
UI بطاقة "ما الأهم عندك"  →  ViewModel  →  Engine  →  Prop  →  Objective  →  القرار
```

- **الواجهة**: `ObjectivePreferenceCard` تظهر عند تفعيل AI فقط (تفضيل للعقل)
- **الثلاثة أزرار**: الأداء / التوازن / البطارية — تحدد الاتجاه لا الملف
- **النصوص**: 5 موارد × لغتان (ar/en)، XML مُتحقَّق منه
- **الاستيرادات**: أُضيفت `remember`/`mutableStateOf`/`setValue` الناقصة
  (كانت ستُفشل الترجمة)، ووُحّد `OutlinedButton` مع نمط الملف القائم
